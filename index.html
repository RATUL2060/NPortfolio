Featured Project

CardioSense AI

Full-Stack Machine Learning

ReactFastAPIScikit-learnSHAPDocker
01

The Problem

Heart disease remains one of the leading causes of mortality worldwide. Early risk assessment from clinical data can make a meaningful difference — but requires accessible, explainable tools.

02

The System

React → FastAPI → ML Engine → SHAP → SQLite

A layered full-stack architecture: React frontend communicates with a FastAPI backend that routes through authenticated patient management, a Scikit-learn prediction engine, and SHAP explainability. Containerized with Docker. CI via GitHub Actions.

03

The Result

An end-to-end ML platform: user authentication, patient record management, real-time risk prediction, SHAP-based explanation charts, prediction history, analytics and nearby hospital search using Leaflet/OpenStreetMap.

Educational project — predictions are not medical diagnoses.
